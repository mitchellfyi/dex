# Skill: dxuicapture

This compatibility entrypoint keeps the lifecycle UI-proof decision separate
from an explicit manual capture request. Use **lifecycle decision mode** from
`prompts/ui-proof.md` and follow that prompt end to end.

When the user explicitly asks for visual artifacts, use manual proof mode just
as `/dxproof` and `/dxcapture` do.
