# Skill: dxproof

Use **manual proof mode** from `prompts/ui-proof.md` and follow that prompt end
to end. Infer the visual scope from the complete diff against the current
branch's comparison base, reconstruct the baseline in an isolated worktree,
and capture the matched before and after experience.

Treat any arguments supplied with `/dxproof` as explicit capture constraints.
